# Forge iOS — Port Progress Log

Durable, append-only record of every build/test iteration. The **last entry under "Run log" is the
current state.** Structured run entries are generated by `scripts/ios-run.sh` (raw artifacts —
forge.log, crash reports — land under `build/ios-logs/<stamp>/`, which is git-ignored; only this
summary is committed). See `IOS_PORT.md` for the full engineering handoff.

**Recommended loop:** `./scripts/build-ios.sh device`  →  `./scripts/ios-run.sh "what I changed"`
→ read the new entry below → fix the next blocker → repeat.

GL, and the runtime-API shims into `Forge.create()`; crashes loading the 285-constant `FPref` enum
